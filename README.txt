PAVF WEBSITE - how to use
1. Open index.html (or upload the whole folder to your host).
2. New gallery photos: drop them in images/gallery/ then run:  node make-gallery.js
   Name them  sem-...jpg (Seminars), edu-...jpg (Education), out-...jpg (Outreach).
   The words after the prefix become the caption, e.g. out-feeding-dokukrom.jpg
3. Replace these two stock photos with real ones (same file names):
   images/feeding-outreach.jpg  (Dokukrom feeding outreach)  <- currently a stock photo
   images/shoes.jpg             (new shoes for Azindow)  <- currently a stock photo
